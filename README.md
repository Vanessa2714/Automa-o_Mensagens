# Automação de Mensagens pelo WhatsApp com Python

## Sobre o projeto

Desenvolvimento de uma solução em Python para automatizar o envio de mensagens pelo WhatsApp, com foco na comunicação entre uma organização social e os responsáveis pelos alunos atendidos pela instituição.

O projeto surgiu da necessidade de facilitar a comunicação com as famílias, tornando o processo de envio de mensagens mais organizado e reduzindo tarefas manuais.

## Objetivos

- Automatizar o envio de mensagens pelo WhatsApp.
- Organizar os contatos a partir de uma planilha.
- Identificar e agrupar números de telefone repetidos.
- Associar os nomes dos contatos às respectivas mensagens.

## Tecnologias utilizadas

- Python
- Pandas
- PyWhatKit
- PyAutoGUI
- Time
- Random

## Funcionamento

O código utiliza uma planilha CSV como fonte de dados para organizar os contatos.

O processamento contempla:
- Leitura e tratamento da planilha de contatos.
- Padronização dos números de telefone.
- Identificação de contatos com números repetidos.
- Agrupamento dos nomes associados aos contatos.
- Automação da interação com o WhatsApp para o envio das mensagens.

## Aplicação prática

A ferramenta foi desenvolvida para apoiar a comunicação de uma organização social com os responsáveis pelos alunos, demonstrando a aplicação da programação Python na automação de processos cotidianos.

## Tecnologias e impacto social

O projeto conecta programação e tecnologia a uma necessidade real de comunicação institucional, explorando como pequenas soluções de automação podem otimizar atividades de organizações sociais.
